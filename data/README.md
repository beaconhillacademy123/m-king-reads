# Naija Languages data

`naija-stories.json` holds openly licensed (CC BY) storybooks in Hausa, Yorùbá and Nigerian Pidgin from the
[African Storybook](https://africanstorybook.org) via [Global African Storybook Project](https://github.com/global-asp/asp-source)
and [Storybooks Nigeria](https://global-asp.github.io/storybooks-nigeria/). Each record keeps its author, illustrator,
translator and licence for attribution. Non-commercial (CC BY-NC) stories are deliberately excluded.
